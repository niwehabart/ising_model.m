## 1. 2D Ising Model (Monte Carlo Simulation)
*   **File:** `ising_model.py` (or `ising_model.m` if MATLAB)
*   **Description:** This script simulates the 2D Ising model on a square lattice using the Metropolis algorithm. 
*   **What it does:** It calculates thermodynamic properties (magnetization, specific heat, and magnetic susceptibility) across a range of temperatures to identify the phase transition at the Curie temperature.
*   **How to run:** Run the script in a Python/MATLAB environment. You will be prompted to enter the lattice size (L) and initial conditions (positive, negative, or random spins).

## Requirements
*  MATLAB R2020b+
